# SK Square AI Board PPT 템플릿 명세서

> 이 문서는 PPT 생성의 **진실의 원천(Source of Truth)** 입니다.
> Claude Code는 슬라이드를 생성할 때 이 명세의 수치·컬러·규칙을 임의 변형 없이 그대로 반영해야 합니다.

---

## 1. 기본 레이아웃

### 1.1 슬라이드 규격
- **용지 규격**: A4 **가로형 (Landscape)**
- **크기**: 297mm × 210mm (29.7cm × 21.0cm)
- **python-pptx 설정**:
  ```python
  from pptx.util import Cm
  prs.slide_width  = Cm(29.7)   # 가로
  prs.slide_height = Cm(21.0)   # 세로
  ```

### 1.2 여백 / 정렬 원칙
- **배경**: `#FFFFFF` (White) 고정
- **정렬 기준선**: **좌측 정렬 단일 기준선** — 제목 / 본문 / 각주 모두 동일한 좌측 기준선 사용
- **상단 영역**: 얇은 구분선(Divider) 배치 → 구분선 아래가 본문 영역
- **권장 여백** (가로형 기준):
  - 상단: 1.2cm (구분선 위)
  - 좌측: 2.0cm (정렬 기준선)
  - 우측: 1.5cm
  - 하단: 1.2cm
- **가용 본문 영역**: 약 26.2cm(가로) × 18.6cm(세로)

### 1.3 페이지 하단 고정 요소
- **우하단**: 페이지 번호 + 로고 (표지 포함 **모든** 슬라이드)
- 로고와 페이지 번호는 가로로 나란히 배치 권장 (예: `[로고]  3 / 12`)

## 2. 색상 팔레트

| 용도 | 역할 | HEX | RGB | 사용 규칙 |
|------|------|-----|-----|----------|
| Background | 배경 | `#FFFFFF` | (255, 255, 255) | 모든 슬라이드 고정 |
| Text | 본문 텍스트 | `#000000` | (0, 0, 0) | 기본 블랙 계열 |
| **Primary** | 포인트 / 키워드 | `#034750` | (3, 71, 80) | 딥 틸 — 주요 키워드, 소제목 |
| **Secondary** | 인용 / 강조 | `#156082` | (21, 96, 130) | 블루 계열 — 인용, 부가 강조 |
| **Alert** | 핵심 붉은 포인트 | `#C00000` | (192, 0, 0) | 레드 — 핵심 결론, 경고, 수치 강조 |
| Divider | 상단 구분선 | `#000000` | (0, 0, 0) | 얇은 선(0.5~1pt) |

### 2.1 컬러 사용 규칙 (엄격)
- ✅ 컬러 텍스트는 **"키워드 / 라벨"에만** 사용
- ❌ **문장 전체를 컬러로 칠하는 것 금지**
- ❌ 한 슬라이드에 3개 초과 컬러 사용 금지 (Primary/Secondary/Alert 조합 최소화)
- ❌ 그라데이션, 그림자, 네온 효과 등 장식 효과 일체 금지

## 3. 폰트

### 3.1 폰트 패밀리
- **원칙**: **나눔스퀘어 (NanumSquare)** 단일 패밀리
- 대체 폰트: 없음 (회사 표준)

### 3.2 폰트 가중치 및 크기 가이드 (가로형 기준)

| 용도 | 두께(Weight) | 크기(pt) | 비고 |
|------|-------------|---------|------|
| 표지 타이틀 | Bold | 36~44pt | 1~2줄 결론형·명사형 |
| 본문 슬라이드 제목 | Bold | 16pt | 1~2줄 결론형·명사형 |
| 소제목 (###) | Bold | 16pt | `[참고]`·`[별첨]` 라벨 포함 |
| 본문 (불릿) | Regular | 11~13pt | 3~6줄 불릿 |
| 강조 키워드 | Bold | 본문 크기와 동일 | 굵게 + 컬러 병용 가능 |
| 각주 / 출처 | Regular | 9~10pt | 하단 좌측 정렬 |
| 페이지 번호 | Regular | 9~10pt | 우하단 고정 |

> 가로형은 세로형보다 가독 거리가 짧고 표시 영역이 넓으므로 제목/본문 모두 소폭 키워 사용합니다.

### 3.3 문장 규칙
- **제목**: 결론형 / 명사형 (예: "AI 에이전트 도입으로 업무 효율 40% 개선", "회의 문화 혁신 3대 과제")
- **본문**: 불릿 리스트로만 구성, **줄글 금지**
- **강조**: Bold 처리. 색상은 키워드 단위로만 사용

## 4. 슬라이드 구성

### 4.1 표지 (`#`)
- **구성 요소**:
  - 중앙 타이틀 (Bold 36~44pt)
  - 하단 날짜: `'26.04` 형식 (연도 뒤 2자리 + 점 + 월 2자리)
  - 우하단: 로고 + 페이지 번호(1)
- **배치** (가로형):
  ```
  ┌──────────────────────────────────────────────────────┐
  │ ──────────────────────────────────────────────────── │ ← 상단 구분선
  │                                                      │
  │                                                      │
  │                                                      │
  │                 [중앙 타이틀]                         │
  │              (Bold 36~44pt, 1~2줄)                    │
  │                                                      │
  │                                                      │
  │                    '26.04                            │
  │                                                      │
  │                                          [로고]   1  │
  └──────────────────────────────────────────────────────┘
  ```

### 4.2 목차
- **자동 생성**: On (Claude Code가 본문 `##` 제목을 수집해 자동 생성)
- **항목 수**: 5~8개 (권장)
- **형식**: 번호 + 제목 (예: `1. 추진 배경`, `2. 현황 진단`, `3. 실행 방안`)
- **정렬**: 좌측 정렬
- **가로형 활용**: 항목 수가 7~8개 이상이면 2열 배치 허용 (좌측 1~4 / 우측 5~8)

### 4.3 본문 (`##`)

#### 4.3.1 제목 영역 (고정)
- **위치**: 상단 15~20% 영역 → 세로 21cm 기준 약 **3.2~4.2cm**
- **구조**: 상단 구분선 → 그 아래 좌측에 제목
- **원칙**: **1 슬라이드 = 1 메시지** → 결론을 제목에 박아넣기
- **예**:
  - ✅ "AI Board 도입으로 의사결정 속도 2배 향상"
  - ❌ "AI Board 관련 내용"

#### 4.3.2 본문 레이아웃 우선순위 (4종)

**Claude Code는 컨텐츠를 분석해 아래 4가지 레이아웃 중 가장 적합한 것을 선택하고, 추천 근거를 함께 출력한다. 가로형 슬라이드는 좌우 분할 구조가 특히 유리하다.**

##### 레이아웃 (A) — 2단 구성 (현황 vs 방향)
- 사용 시점: **현황/문제**와 **방향/결론**을 대비시킬 때
- 가로형 구조 (좌우 대등 분할):
  ```
  ┌──────────────────────────────────────────────────────┐
  │ ──────────────────────────────────────────────────── │
  │ [제목: 결론형]                                        │
  │                                                      │
  │ ┌────────────────────┬───────────────────────────┐   │
  │ │ 현황 / 근거         │ 방향 / 결론                │   │
  │ │                    │                           │   │
  │ │ - 불릿 1           │ - 불릿 1                  │   │
  │ │ - 불릿 2           │ - 불릿 2                  │   │
  │ │ - 불릿 3           │ - 불릿 3                  │   │
  │ │ - 불릿 4           │ - 불릿 4                  │   │
  │ └────────────────────┴───────────────────────────┘   │
  │                                          [로고]  N   │
  └──────────────────────────────────────────────────────┘
  ```
- 좌/우 컬럼 폭: 가용 본문 영역의 약 48% / 48% (중앙 4% gutter)

##### 레이아웃 (B) — STEP 단계형 (메시지 + 실행계획)
- 사용 시점: **순차적 실행 단계**를 제시할 때
- 가로형 구조:
  - 좌측 약 30%: 핵심 메시지 / 요약
  - 우측 약 70%: STEP 1 → STEP 2 → STEP 3 가로 흐름 (화살표 연결)
- STEP 번호는 Primary 컬러(`#034750`) Bold 처리
- STEP 최대 개수: 5개 (가로로 배치 가능한 최대치)

##### 레이아웃 (C) — 타임라인 (가로형의 강점 레이아웃)
- 사용 시점: **연도별 · 월별 로드맵** 제시
- 가로형 구조: **화면 가로 전체를 활용한 수평 타임라인**
  ```
  ────●────────●────────●────────●────────●──→
     '24      '25      '26      '27      '28
     과거     현재     단기      중기     장기
  ```
- 각 시점별 이벤트 박스는 축 위/아래 번갈아 배치 (시각 밀도↑)
- 색상 구분: 과거 `#666666` / 현재 `#034750` / 미래 `#156082`

##### 레이아웃 (D) — Resource Plan (항목 열거)
- 사용 시점: **자원 / 인력 / 예산 / 제약** 항목 나열
- 가로형 구조: 표 형태의 항목형 정리 (정의 / 계획 / Target / 제약)
- 가로형에서는 **열(Column)을 4~6개까지 확장 가능** (세로형 대비 장점)

#### 4.3.3 본문 문장 규칙
- 불릿 기호: `-` (하이픈) 기본
- 단계 표현: `STEP 1/2/3` 또는 번호 `1. 2. 3.` — 한 슬라이드 내 **일관성 유지**
- 불릿 줄 수: 3~6줄 권장
- 각 불릿은 **2줄 이내** 작성
- 결론/주장 → 근거 순서로 배치

### 4.4 섹션 구분 (`###`)
- **원칙**: **별도 섹션 구분 슬라이드 없음**
- 본문 슬라이드 내부에서 `###` 소제목 라벨로 처리
- **라벨 규칙**:
  - `[참고]` — 보조 자료 · 추가 설명
  - `[별첨]` — 상세 데이터 · 부록
  - 제목 앞에 **대괄호**로 반드시 표기 (예: `[참고] 국내외 AI Board 도입 사례`)
- **내용 구성**: "표 / 항목형"으로 **밀도 높게** 구성 (정의서 스타일)
- **가로형 활용**: 표를 가로로 넓게 펼쳐 항목을 최대한 한 페이지에 담음

## 5. 기타 요소

### 5.1 헤더 / 푸터
- **헤더**: 별도 헤더 없음 (상단 구분선 + 제목이 헤더 역할 수행)
- **푸터**:
  - 우하단 페이지 번호 (고정)
  - 우하단 로고 (표지 포함 전 슬라이드)
  - 좌측 하단: 비움 또는 각주 (출처 등)

### 5.2 불릿 기호
- 1차 불릿: `-` (하이픈)
- 2차 불릿: `·` (가운뎃점, 들여쓰기 0.5cm)
- 단계형 표현: `STEP 1`, `STEP 2` 또는 `1.`, `2.` (둘 중 하나로 통일)

### 5.3 표 스타일 (정의서 스타일)
- 용도: **정의 / 계획 / Target / 제약조건** 등 항목형 정리
- 헤더 행:
  - 배경: `#034750` (Primary)
  - 텍스트: 흰색 Bold
- 본문 행:
  - 배경: 흰색
  - 텍스트: 블랙
- 테두리: 가로선 `#000000` 얇은 선(0.5pt), 세로선 최소화
- 짝수 행 음영: 사용하지 않음 (정보 밀도 우선)
- **가로형 장점**: 열 수를 4~6개까지 확장해 한 페이지에 밀도 있는 정의서 구성 가능

### 5.4 이미지 · 도식
- **사용 원칙**: 메시지 **보조용으로만** 사용
- **수량 제한**: 슬라이드당 1~2개 이내
- **용도**: 순수 장식 이미지 금지, 정보 전달 목적의 다이어그램/차트만 허용
- **정렬**: 좌측 기준선에 맞춰 배치
- **가로형 배치**: 텍스트와 이미지를 좌/우로 배치하는 구조 권장 (상/하 분할은 지양 — 가로형은 세로 공간이 제한적)

### 5.5 출처 / 각주
- **위치**: 슬라이드 하단 좌측
- **크기**: 9~10pt Regular
- **형식**: `* 출처: OOOO, YYYY` 또는 `1) 설명`
- **색상**: 블랙(`#000000`), 컬러 처리 금지

## 6. 톤앤매너

- **보고 대상**: CEO, 임원, AI Board 구성원
- **문체 원칙**:
  - 결론 먼저 (Conclusion First)
  - 단정형 종결 ("~이다", "~해야 한다")
  - 모호한 표현 금지 ("~할 수 있을 것으로 보임", "~인 듯함" ❌)
  - 수식어 최소화, 명사형·결론형 제목 우선
- **데이터 처리**:
  - 수치는 반드시 단위 명시 (`40%`, `3배`, `₩1.2억`)
  - 핵심 수치는 Bold + Alert 컬러(`#C00000`)로 강조
  - 출처 없는 수치 사용 금지

## 7. 금지 사항 체크리스트

생성된 PPT가 아래 항목 중 하나라도 해당되면 **반드시 수정**:

- [ ] 슬라이드 규격이 A4 가로형(29.7cm × 21.0cm)이 아님
- [ ] 나눔스퀘어 외 폰트 사용
- [ ] 문장 전체를 컬러로 칠함
- [ ] 한 슬라이드에 3개 초과 컬러 사용
- [ ] 그라데이션 · 그림자 · 네온 효과 사용
- [ ] 본문에 줄글 문단 포함 (불릿이 아닌 산문)
- [ ] 제목이 결론형이 아닌 단순 토픽형 (예: "현황")
- [ ] 페이지 번호 또는 로고 누락
- [ ] 이미지가 슬라이드당 3개 이상
- [ ] 애니메이션 / 전환 효과 포함
- [ ] 별도의 섹션 구분 슬라이드 생성
- [ ] `[참고]` / `[별첨]` 라벨 누락
